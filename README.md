# Tic Tac Toe - React + JavaScript

A two-player Tic Tac Toe game with score counter. Built for BCA practice.

## Run
Install Node.js (nodejs.org), then:

    npm install
    npm run dev

## Upload to GitHub
    git init
    git add .
    git commit -m "Tic Tac Toe game"
    git branch -M main
    git remote add origin https://github.com/<your-username>/<repo>.git
    git push -u origin main

## Free hosting (GitHub Pages)
    npm run deploy
Then repo -> Settings -> Pages -> Source: branch `gh-pages`, folder `/ (root)`.
